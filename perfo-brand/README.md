# Perfo brand kit

- `logo/` logo ngang, dọc, wordmark, biểu tượng (nền sáng, nền tối, mono đen, mono trắng)
- `app/` favicon, app icon 512 (thường + maskable), avatar 400
- `banner/` ảnh chia sẻ 1200x630, ảnh bìa 1640x624
- `icons/` 15 icon 24px (stroke = currentColor) + sprite
- `pattern/` họa tiết dải lỗ phim, chấm đục lỗ (tile lặp)
- `template/` mẫu vé điện tử
- `react/` BrandMark + BrandWordmark dùng token Tailwind của project
- `perfo-brand-guide.svg` bản tổng hợp; `slogans.md` slogan và giọng nói

Wordmark và biểu tượng là path thuần nên không phụ thuộc font. Chữ slogan trong banner/guide dùng Oswald và Geist (đã có trong project); máy không có font sẽ tự rơi về font dự phòng.
